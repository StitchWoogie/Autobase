1. 소개
================================================================================

AutobasePrime의 레시피(Recipe)와 프리셋(Preset) 기능은 산업 자동화
공정에서 태그 값을 체계적으로 관리하고 실행하는 도구입니다.

  레시피(Recipe): 공정 절차를 Step 단위로 정의하고 순차 실행
  프리셋(Preset): 태그 값 묶음을 저장하고 일괄 적용/캡처

두 기능 모두 ISA-88 배치 제어 표준을 기반으로 설계되었습니다.


2. 레시피 (Recipe)
================================================================================

2.1 레시피란?
─────────────

레시피는 공정에 필요한 태그 설정값과 실행 조건을 정의한 문서입니다.

  구조:
    레시피
    ├─ 직속 Step (순차 실행)
    │   ├─ Step 1: 온도 설정 → AO_TEMP = 80
    │   ├─ Step 2: 압력 대기 → AI_PRESSURE >= 2.5 충족 시 다음
    │   └─ Step 3: 밸브 개방 → DO_VALVE = 1
    └─ Unit (병렬 실행 가능)
        ├─ Unit A: 배합기
        │   ├─ Step 1: 원료 투입
        │   └─ Step 2: 교반 시작
        └─ Unit B: 가열기
            ├─ Step 1: 히터 ON
            └─ Step 2: 온도 안정 대기


2.2 실행 모드
─────────────

  ┌──────────────┬──────────────────────┬────────────────────────────┐
  │              │ Quick 모드            │ Standard 모드               │
  ├──────────────┼──────────────────────┼────────────────────────────┤
  │ 용도         │ 단순 태그값 일괄 출력 │ 조건부 순차/병렬 실행      │
  │ 시작 조건    │ 없음                  │ 설정 가능                  │
  │ 전이 조건    │ 없음                  │ 설정 가능 (여러 개)        │
  │ 종료 동작    │ 없음                  │ Exit Actions 실행          │
  │ 비상 동작    │ 없음                  │ Abort Actions 실행         │
  │ Unit 지원    │ 미지원                │ 병렬 실행 지원             │
  │ 일시정지     │ 미지원                │ Hold/Resume/Abort 지원     │
  │ 전자서명     │ 불필요                │ 배치 시작 시 필요          │
  └──────────────┴──────────────────────┴────────────────────────────┘

  Quick 모드: 정해진 태그값을 즉시 출력 (조건 없음)
  Standard 모드: ISA-88 기반 배치 실행 (조건, 전이, 안전 감시 포함)


2.3 레시피 설정 화면
────────────────────

  Studio에서 메뉴 → 레시피 설정 선택

  ┌─────────────────────────────────────────────────────────────┐
  │ 레시피 설정                                                  │
  ├───────────┬─────────────────────────────────────────────────┤
  │ 레시피    │  이름: [배합레시피A          ]                   │
  │ 목록      │  설명: [원료 배합 공정       ]                   │
  │           │  모드: [Standard  ▼]   상태: APPROVED           │
  │ ─────── │                                                  │
  │ 배합A  3 │  ┌─ (Direct)                                    │
  │ 배합B  1 │  │   ├─ [0] 온도설정 [3]                         │
  │ 세정   2 │  │   └─ [1] 압력대기 [2]                         │
  │           │  ├─ Unit 1: 배합기                               │
  │           │  │   ├─ [0] 원료투입 [4]                         │
  │           │  │   └─ [1] 교반시작 [2]                         │
  │           │  └─ Unit 2: 가열기                               │
  │           │      └─ [0] 히터ON [1]                           │
  └───────────┴─────────────────────────────────────────────────┘

  왼쪽: 레시피 목록 (이름, 버전, 설명)
  오른쪽: 선택된 레시피의 구조 트리 + Step 미리보기


2.4 레시피 만들기
─────────────────

  ① 도구모음에서 "레시피 추가" 클릭
  ② 이름, 설명, 모드(Standard/Quick) 입력
  ③ Unit 추가 (Standard 모드만): "Unit 추가" 클릭 → 이름 입력
  ④ Step 추가: 트리에서 위치 선택 → "Step 추가" 클릭
  ⑤ Step 편집 다이얼로그에서 설정:
     - 태그-값 항목 추가 (Tag 이름, 설정값, 데이터 타입)
     - 시작 조건 (Entry): 언제 Step을 시작할지
     - 전이 조건 (Transition): 언제 다음으로 넘어갈지
     - 종료 동작 (Exit Actions): 정상 완료 시 실행할 태그 값
     - 비상 동작 (Abort Actions): 오류/중단 시 실행할 태그 값
  ⑥ "저장" 클릭 → 버전 자동 증가


2.5 Step 편집 상세
──────────────────

  (1) 태그-값 항목 (Items)
      모든 모드에서 사용. Step 실행 시 해당 태그에 값을 출력합니다.
      예: AO_TEMP_SP = 80, DO_VALVE = 1

  (2) 시작 조건 (Entry Expression) — Standard만
      Step 실행 전에 충족해야 할 조건.
      예: $DI_READY == 1
      타임아웃 설정 가능 (초과 시 비상 동작 실행)

  (3) 전이 조건 (Transitions) — Standard만
      Step 완료 후 다음으로 넘어가는 조건.
      여러 개 정의 가능하며, 우선순위에 따라 평가됩니다.

      전이 유형:
      ┌──────────┬──────────────────────────────────────────────┐
      │ Complete │ 정상 완료. 다음 Step으로 이동                │
      │ Exception│ 이상 감지. 비상 동작 실행 후 배치 실패       │
      │ Abort    │ 즉시 중단. 비상 동작 실행 후 배치 중단       │
      │ Loop     │ 지정된 Step으로 되돌아가기 (반복 횟수 제한)  │
      │ End      │ 레시피 전체 종료 (남은 Step/Unit 건너뛰기)   │
      └──────────┴──────────────────────────────────────────────┘

      평가 순서 (안전 우선):
        1순위: Abort (비상 정지) — 항상 가장 먼저 확인
        2순위: Exception (이상 감지) — 그 다음 확인
        3순위: Complete / Loop / End — 마지막에 확인

      예시:
        P0  Exception  $AI_PRESSURE > 5.0    "과압 감지"
        P10 Complete   $AI_TEMP >= 80        "목표 온도 도달"
        P20 Loop→Step0 $AI_TEMP < 50 (Max:3) "온도 미달 시 재시도"

  (4) 종료 동작 (Exit Actions) — Standard만
      정상 완료(Complete, End) 시 실행할 태그 설정.
      예: $AO_VALVE=0;$DO_PUMP=0 (밸브 닫기, 펌프 정지)

  (5) 비상 동작 (Abort Actions) — Standard만
      이상/중단/타임아웃 시 실행할 안전 조치.
      예: $DO_ESTOP=1;$AO_VALVE=0 (비상정지, 밸브 닫기)


2.6 조건식 문법
───────────────

  태그 참조: $ 기호 + 태그이름
    예: $AI_TEMP, $DI_READY, $ST_MODE

  비교 연산자: ==, !=, >, <, >=, <=
    예: $AI_TEMP >= 80

  논리 연산자: && (그리고), || (또는), ! (아님)
    예: $AI_TEMP > 80 && $DI_READY == 1
    예: !($DO_RUNNING == 1)

  괄호: 우선순위 지정
    예: ($AI_TEMP > 80 || $AI_TEMP < 10) && $DI_READY == 1

  문자열 비교:
    예: $ST_MODE == 'AUTO'


2.7 레시피 상태와 승인
──────────────────────

  레시피에는 3가지 상태가 있습니다:

  ┌──────────┬────────┬────────────────────────────────────────┐
  │ 상태      │ 색상   │ 설명                                    │
  ├──────────┼────────┼────────────────────────────────────────┤
  │ DRAFT    │ 주황   │ 초안. 편집 가능, 실행 불가               │
  │ APPROVED │ 초록   │ 승인됨. 실행 가능                        │
  │ OBSOLETE │ 회색   │ 폐기. 실행 불가                          │
  └──────────┴────────┴────────────────────────────────────────┘

  승인(Approve) 절차:
    ① 전자서명 다이얼로그가 표시됩니다
    ② 현재 로그인 사용자의 비밀번호를 다시 입력합니다
    ③ 승인 사유를 입력합니다 (필수)
    ④ 비밀번호가 맞으면 상태가 APPROVED로 변경됩니다
    ⑤ 비밀번호를 5회 틀리면 자동으로 취소됩니다

  승인된 레시피만 실행할 수 있습니다.


2.8 배치 실행 (Standard 모드)
─────────────────────────────

  Standard 모드 레시피를 실행하면 "배치(Batch)"가 생성됩니다.

  배치 상태 흐름:

    대기(Idle) → 실행(Running) → 완료(Complete)
                     │
               Hold  │ Restart
                     ▼
              일시정지(Holding → Held) → 재개(Running)
                     │
               Abort │
                     ▼
                   중단(Aborting → Aborted)

  조작:
    Hold    실행 일시정지 (현재 Step 대기 상태에서 정지)
    Restart Hold 상태에서 실행 재개
    Abort   실행 중단 (비상 동작 실행 후 중단)


2.9 CSV 가져오기/내보내기
─────────────────────────

  레시피를 CSV 파일로 내보내거나 가져올 수 있습니다.

  내보내기:
    ① 레시피 선택 → "CSV 내보내기" 클릭
    ② 저장 위치 지정 → CSV 파일 생성

  가져오기:
    ① "CSV 가져오기" 클릭 → CSV 파일 선택
    ② 같은 이름 존재 시 덮어쓰기 여부 확인
    ③ 자동 저장 후 목록에 추가


3. 프리셋 (Preset)
================================================================================

3.1 프리셋이란?
───────────────

프리셋은 여러 태그의 값을 하나의 묶음으로 저장하는 기능입니다.
저장된 값을 언제든지 태그에 일괄 적용하거나,
현재 태그 값을 캡처하여 저장할 수 있습니다.

  예시: "온도 프리셋"
    ┌───────────────────────────────────────────────┐
    │ 별칭 매핑 (Alias Map)                          │
    │  설정온도  → AO_TEMP_SP                        │
    │  상한경보  → AO_TEMP_HI                        │
    │  하한경보  → AO_TEMP_LO                        │
    ├───────────────────────────────────────────────┤
    │ Variant: "여름"                                │
    │  설정온도 = 25, 상한경보 = 30, 하한경보 = 20   │
    ├───────────────────────────────────────────────┤
    │ Variant: "겨울"                                │
    │  설정온도 = 22, 상한경보 = 26, 하한경보 = 18   │
    └───────────────────────────────────────────────┘


3.2 별칭 매핑 (Alias Map)
─────────────────────────

별칭(Alias)은 태그에 부여하는 사용자 친화적인 이름입니다.

  장점:
  - 실제 태그명(AO_TEMP_SP) 대신 이해하기 쉬운 이름(설정온도) 사용
  - 태그 이름이 변경되어도 Alias Map만 수정하면 모든 Variant에 반영
  - 같은 태그 구조를 여러 프리셋에서 재사용 가능

  Alias Map은 프리셋 전체에 하나만 존재하며,
  모든 Variant가 같은 Alias Map을 공유합니다.


3.3 Variant (변형)
──────────────────

하나의 프리셋에 여러 Variant를 만들 수 있습니다.
각 Variant는 같은 별칭 목록에 대해 다른 값을 가집니다.

  예시:
    프리셋 "반응기 설정"
    ├─ Variant "제품A" : 온도=80, 압력=2.0, 속도=500
    ├─ Variant "제품B" : 온도=95, 압력=3.5, 속도=700
    └─ Variant "세정"  : 온도=60, 압력=1.0, 속도=300


3.4 프리셋 설정 화면
────────────────────

  Studio 또는 LocalMain에서 메뉴 → 프리셋 설정 선택

  ┌─────────────────────────────────────────────────────────────┐
  │ 프리셋 설정                                                  │
  ├──────────┬──────────────────────────────────────────────────┤
  │ 프리셋   │  이름: [온도 프리셋        ]                     │
  │ 목록     │                                                  │
  │          │  ▼ 별칭 매핑 (Alias Map)                         │
  │ ──────── │  ┌────────┬──────────────┬───┐                  │
  │ 온도   2 │  │ 별칭    │ 태그          │...│                 │
  │ 압력   3 │  ├────────┼──────────────┼───┤                  │
  │ 배합   1 │  │ 설정온도 │ AO_TEMP_SP   │[…]│                 │
  │          │  │ 상한경보 │ AO_TEMP_HI   │[…]│                 │
  │          │  └────────┴──────────────┴───┘                  │
  │          │                                                  │
  │          │  Variants: [여름] [겨울]                          │
  │          │  ┌────────┬───────┐                              │
  │          │  │ 별칭    │ 값     │                             │
  │          │  ├────────┼───────┤                              │
  │          │  │ 설정온도 │ 25    │                             │
  │          │  │ 상한경보 │ 30    │                             │
  │          │  └────────┴───────┘                              │
  └──────────┴──────────────────────────────────────────────────┘


3.5 프리셋 만들기
─────────────────

  ① "새로만들기" 클릭 → 프리셋 이름 입력
  ② 별칭 매핑 설정:
     - "+ 추가" 클릭하여 행 추가
     - "별칭" 열에 이름 입력 (예: 설정온도)
     - "[…]" 버튼으로 태그 선택 또는 "태그" 열에 직접 입력
  ③ Variant 추가:
     - "+ 추가" 클릭 → Variant 이름 입력
     - 각 별칭에 대한 값 입력
  ④ "저장" 클릭


3.6 태그 적용 (Apply) — RUN 모드
─────────────────────────────────

현재 선택된 Variant의 값을 실제 태그에 출력합니다.

  ① 프리셋 선택
  ② Variant 탭 선택
  ③ "▶ 적용" 클릭
  ④ 확인 메시지에서 "예" 선택
  ⑤ 각 별칭을 Alias Map으로 태그 변환 후 값 출력
  ⑥ 결과 표시: "성공 N, 실패 M"

  주의: RUN 모드에서만 사용 가능합니다.


3.7 태그 캡처 (Capture) — RUN 모드
───────────────────────────────────

현재 태그 값을 읽어서 프리셋에 저장합니다.

  ① 프리셋 선택, Variant 선택
  ② "◎ 캡처" 클릭
  ③ 저장할 프리셋 이름 입력 (기존 이름 사용 시 해당 Variant 덮어쓰기)
  ④ Alias Map에 정의된 태그의 현재값을 읽어 저장
  ⑤ 결과 표시: "N개 태그 값 저장"

  용도:
  - 현재 운전 상태를 프리셋으로 백업
  - 최적 운전 조건 발견 시 캡처하여 재사용


3.8 CSV 가져오기/내보내기
─────────────────────────

  내보내기:
    프리셋 선택 → "↑ 내보내기" → 저장 위치 선택
    CSV 형식: Preset, Variant, Alias, Tag, Value

  가져오기:
    "↓ 가져오기" → CSV 파일 선택 → 새 프리셋 이름 입력
    자동 생성: Alias Map + Variant + Items


3.9 별칭 매핑 접기/펼치기
─────────────────────────

  "▼ 별칭 매핑" 라벨을 클릭하면 Alias Map 영역이 접히거나 펼쳐집니다.
  접은 상태: "▶ 별칭 매핑"
  편집할 때만 펼쳐서 사용하면 화면을 효율적으로 사용할 수 있습니다.


3.10 행 순서 변경
─────────────────

  Items 그리드에서 행 순서를 변경할 수 있습니다:
  - Up/Down 버튼으로 한 칸씩 이동
  - 마우스 드래그 앤 드롭으로 원하는 위치에 배치


4. 전자서명
================================================================================

4.1 전자서명이란?
─────────────────

전자서명은 중요한 조작(레시피 승인, 배치 시작/중단 등)에 대한
본인 확인 및 감사 추적 기능입니다.

  절차:
    ① 조작 시 전자서명 다이얼로그가 자동으로 표시됩니다
    ② 사용자 이름이 표시됩니다 (변경 불가)
    ③ 비밀번호를 입력합니다
    ④ 사유를 입력합니다 (필수)
    ⑤ "확인" 클릭

  결과:
    성공 시: 조작이 수행되고 서명 기록이 저장됩니다
    실패 시: 비밀번호 오류 횟수가 표시됩니다

  보안:
    - 비밀번호 5회 연속 오류 시 자동 취소
    - 서명 결과에 사용자, 시각, 조작, 사유가 기록됩니다


4.2 전자서명이 필요한 조작
──────────────────────────

  Standard 모드:
    - 레시피 승인 (Approve)
    - 배치 시작 (Batch Start)
    - 배치 중단 (Batch Abort)

6. 안전 보호 기능
================================================================================

Standard 모드 배치 실행 시 다중 안전 보호가 적용됩니다:

  ┌─────────────────────────┬──────────────┬──────────────────────────┐
  │ 보호 기능                │ 기본 제한     │ 동작                      │
  ├─────────────────────────┼──────────────┼──────────────────────────┤
  │ Step별 반복 횟수 제한    │ 최대 10회    │ 초과 시 비상 동작 실행    │
  │ 총 Step 실행 횟수 제한   │ 최대 10,000  │ 초과 시 비상 동작 실행    │
  │ 총 전이 평가 횟수 제한   │ 최대 100만   │ 초과 시 비상 동작 실행    │
  │ 배치 실행 시간 제한      │ 최대 24시간  │ 초과 시 비상 동작 실행    │
  └─────────────────────────┴──────────────┴──────────────────────────┘

  Abort 전이 (비상정지)는 항상 가장 먼저 평가됩니다.
  → 사용자가 우선순위를 잘못 설정해도 비상 정지가 보장됩니다.


7. 스크립트에서 프리셋 사용
================================================================================

SCADA 스크립트에서 프리셋 기능을 호출할 수 있습니다:

  프리셋 적용:
    PresetApply("온도프리셋", "여름")
    → 선택된 Variant의 값을 태그에 일괄 출력

  현재값 캡처:
    PresetCapture("온도프리셋", "여름", "백업프리셋")
    → 현재 태그값을 읽어 새 프리셋에 저장

  프리셋 목록 조회:
    PresetGetList()
    → 모든 프리셋 이름 목록 반환

  Variant 수 조회:
    PresetGetVariantCount("온도프리셋")
    → Variant 개수 반환

  Variant 이름 조회:
    PresetGetVariantName("온도프리셋", 0)
    → 첫 번째 Variant 이름 반환


8. 용어 정리
================================================================================

  ┌──────────────────┬──────────────────────────────────────────────┐
  │ 용어              │ 설명                                         │
  ├──────────────────┼──────────────────────────────────────────────┤
  │ Recipe (레시피)   │ 공정 절차 정의서 (Step 묶음)                 │
  │ Step             │ 실행 단위 (태그값 + 조건)                    │
  │ Unit             │ 장치 단위 (Step 묶음, 병렬 실행)             │
  │ Item             │ 태그-값 쌍 (태그에 출력할 값)                │
  │ Transition       │ 전이 조건 (다음 동작 결정)                   │
  │ Batch            │ 레시피 1회 실행 인스턴스                     │
  │ Entry Condition  │ Step 시작 전 충족해야 할 조건                │
  │ Exit Actions     │ 정상 완료 시 실행할 태그 설정                │
  │ Abort Actions    │ 비정상 종료 시 실행할 안전 조치              │
  │ Preset (프리셋)   │ 태그 값 묶음 (일괄 적용/캡처)               │
  │ Alias Map        │ 별칭 ↔ 태그 매핑 테이블                     │
  │ Variant          │ 프리셋의 값 변형 (같은 구조, 다른 값)        │
  │ Apply            │ 프리셋 값을 태그에 출력                      │
  │ Capture          │ 현재 태그값을 프리셋에 저장                  │
  │ E-Signature      │ 전자서명 (본인 확인 + 사유 기록)             │
  │ ISA-88           │ 배치 제어 국제 표준                          │
  │ Draft            │ 초안 상태 (편집 가능, 실행 불가)             │
  │ Approved         │ 승인 상태 (실행 가능)                        │
  │ Obsolete         │ 폐기 상태 (실행 불가)                        │
  │ Hold             │ 배치 일시 정지                               │
  │ Quick 모드       │ 단순 태그값 일괄 출력 모드                   │
  │ Standard 모드    │ ISA-88 기반 조건부 실행 모드                 │
  │ Expression       │ 조건식 ($TAG > 값 형식)                      │
  └──────────────────┴──────────────────────────────────────────────┘


9. FAQ (자주 묻는 질문)
================================================================================

  Q: 레시피를 실행할 수 없습니다.
  A: 레시피 상태가 "APPROVED"인지 확인하세요.
     Draft 또는 Obsolete 상태에서는 실행할 수 없습니다.

  Q: 프리셋의 Apply/Capture 버튼이 보이지 않습니다.
  A: RUN 모드에서만 표시됩니다.
     Studio 편집 모드에서는 설정만 가능합니다.

  Q: 전자서명에서 비밀번호가 맞는데 실패합니다.
  A: 계정이 잠금 상태일 수 있습니다. 관리자에게 문의하세요.
     비밀번호 5회 연속 오류 시 서명이 자동 취소됩니다.

  Q: 프리셋 적용 시 일부 태그만 실패합니다.
  A: 해당 태그가 존재하는지 확인하세요.
     Alias Map의 태그명이 실제 태그와 일치하는지 확인하세요.
     저장 시 태그 검증 경고를 확인할 수 있습니다.

  Q: CSV 가져오기 시 오류가 발생합니다.
  A: CSV 파일 인코딩이 UTF-8인지 확인하세요.
     필수 열(Preset, Variant, Alias, Tag, Value)이 있는지 확인하세요.

  Q: 배치가 자동으로 실패 처리됩니다.
  A: 다음 안전 제한을 확인하세요:
     - Step 반복 횟수 초과 (기본 10회)
     - 총 실행 횟수 초과 (10,000회)
     - 타임아웃 초과
     - 배치 실행 시간 초과 (24시간)
     - 조건식 오류

  Q: Quick 모드와 Standard 모드의 차이는?
  A: Quick 모드는 조건 없이 즉시 태그값을 출력합니다.
     Standard 모드는 시작 조건, 전이 조건, 안전 감시를 포함합니다.
     간단한 설정 변경은 Quick, 공정 제어는 Standard를 사용하세요.

  Q: Unit은 무엇인가요?
  A: Unit은 물리적 장치를 나타내며, 각 Unit의 Step은 병렬 실행됩니다.
     예: 배합기(Unit A)와 가열기(Unit B)가 동시에 실행됩니다.
     Quick 모드에서는 Unit을 사용할 수 없습니다.
