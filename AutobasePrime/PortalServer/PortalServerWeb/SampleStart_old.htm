웹 서버 예제 페이지

이 페이지는 웹서버 예제 페이지입니다. 이 페이지를 직접 사용하지 마시고 다른 이름으로 복사해서 편집하기 바랍니다.

 

1. 웹 클라이언트에서 실행

웹 클라이언트 실행파일 다운로드  - 윈도우즈 전용 프로그램으로 웹서버와 연결하여 감시/제어하는 프로그램. 알맞은 버전을 설치한 후 사이트 메뉴에서 웹서버를 연결하여 사용.

 

2. HTML 실행 방식

모바일 감시 - 모바일 장치에서 감시/제어

 

3. 실버라이트 실행 방식

실버라이트 페이지 - 실버라이트 감시 제어

실버라이트 3 수동 설치 - 인터넷이 연결되지 않은 경우 설치하여 사용한다. 같은 버전이 이미 설치되어 있으면 설치되지 않음
