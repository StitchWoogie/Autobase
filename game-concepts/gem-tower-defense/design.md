# 진법 디펜스 (Jinbeop Defense) — 1페이지 기획서

> **한 줄 피치:** 스타크래프트 명작 유즈맵 "젬 타워 디펜스"를 계승한 싱글플레이 로그라이트 타워 디펜스.
> 랜덤으로 뽑힌 **진법 젬**을 배치해 **미로**를 설계하고, 밀려오는 적 부대를 최대한 오래 가두어 격파한다.
> 삼국지 세계관 + **일일 시드 챌린지**로 차별화한다.

---

## 1. 왜 이 게임인가

| 항목 | 근거 |
|---|---|
| **검증된 재미** | 젬 타디는 워크래프트3/스타크래프트 시절부터 수년간 검증된 프로토타입. 리스크가 낮다. |
| **작은 스코프** | 필요 에셋 = 젬 타워, 크립 몇 종, 격자 맵, UI. 2인 · 2개월 범위 안에서 완성 가능. |
| **멀티 불필요** | 싱글/스코어어택으로 출시 → 실시간 동기화 네트워킹(=천명2를 망하게 한 핵/난관)을 원천 회피. |
| **높은 리플레이성** | 랜덤 젬 드래프트 × 미로 설계 × 조합 승급 = 매판 다른 상황. 스트리머 소재 무한. |
| **상업적 안전성** | 타워 디펜스는 스팀에서 꾸준히 팔리는 장르(블룬스 TD, 킹덤 러시). |

**차별화 후크 (묻히지 않기 위한 3종):**
1. **일일 시드 챌린지** — 매일 전 세계가 같은 랜덤 시드로 경쟁하는 리더보드 (클립·경쟁 유발).
2. **로그라이트 메타 성장** — 판이 끝나도 영구 해금/유물이 쌓인다.
3. **삼국지 진법 테마** — 젬 → 장수 진법. "그때 그 유즈맵의 정식 계승작" 향수 마케팅.

> ⚠️ **법적 주의:** 계승하는 것은 **게임 룰/장르(저작권 보호 대상 아님)**이지 블리자드 에셋이 아니다.
> 유닛·이름·음악·UI·맵은 100% 신규 제작한다. (DotA가 워크3 영웅을 전부 새로 만든 것과 동일.)

---

## 2. 코어 루프

```
① 건설 페이즈  →  ② 방어 페이즈  →  ③ 정산/조합  →  (반복, 30 웨이브)
```

1. **건설 페이즈** — 랜덤 젬 1개를 드래프트. 격자에 배치해 적의 이동 경로(미로)를 늘린다.
   *하나만 남기고 나머지는 팔아 군량(자원)을 회수하는 판단이 핵심 재미.*
2. **방어 페이즈** — 적 부대가 진법을 통과. 경로가 길수록·사거리가 겹칠수록 유리.
3. **정산/조합** — 같은 젬 3개를 모으면 상위 진법으로 **승급**. 군량으로 재드래프트.

**승패 조건:** 적이 성문(라이프)을 30회 뚫리기 전에 30 웨이브 방어 → 승리. 클리어 후 스코어 = 리더보드.

---

## 3. 핵심 시스템

- **젬(진법) 등급:** 일반 → 희귀 → 영웅 → 전설 (4티어). 색/모양으로 즉시 구분.
- **조합 승급 트리:** 예) 자수정 궁병진 ×3 → 벽력차진 / 비취 창병진 ×3 → 백마의종 / 홍옥 화병진 ×3 → 화공진.
- **미로 유효성 검사:** 출구를 완전히 막는 배치는 금지 (아래 4번 참조).
- **유물(로그라이트):** 관통의 옥, 연환계 등. 런 시작 시 1~2개 장착, 클리어로 신규 해금.
- **적 유형:** 보병(기본) / 기병(고속) / 공성(고체력 보스) / 비행(경로 무시 → 특정 젬만 대응).

## 4. 기술 설계

| 영역 | 선택 | 비고 |
|---|---|---|
| **엔진** | Unity (LTS) + C# | 2D 격자 TD 레퍼런스·에셋 풍부. 스팀 파이프라인 검증. |
| **경로탐색** | A* (격자 기반) | 젬 설치 시마다 경로 재계산. **핵심 관문.** |
| **미로 검증** | 설치 전 "경로 존재 여부" 사전 검사 | 출구가 막히면 설치 불가 처리 → 유즈맵 시절 검증된 패턴. |
| **랜덤성** | 시드 기반 PRNG | 일일 시드 챌린지·리플레이·리더보드 공정성의 기반. |
| **저장/메타** | 로컬 세이브 + 스팀 리더보드 API | 서버 운영 부담 0. |
| **아트** | 기하학적 크리스탈 + 빛 이펙트 | 도형+셰이더로 저비용·고품질. 미술 부담 최소. |

> **경로탐색이 유일한 진짜 난제.** "타워 설치 시 A* 경로 재계산 + 완전 봉쇄 금지"는 이미 잘 알려진 문제로,
> 뱀서라이크의 대량 적 렌더링보다 오히려 다루기 쉽다.

## 5. 2개월 마일스톤 (2인 팀)

| 주차 | 목표 (Definition of Done) |
|---|---|
| **W1–2** | **수직 슬라이스:** 격자 + A* 경로탐색 + 젬 1종 설치 + 크립 1종이 미로를 걷는다. *이게 되면 게임의 심장이 뛴다.* |
| **W3–4** | 젬 4~6종 · 조합 승급 · 웨이브/군량 경제 · 승패 판정. 한 판이 처음부터 끝까지 돌아간다. |
| **W5** | 로그라이트 유물 + 메타 해금 + 밸런싱 1차. 적 유형 다양화. |
| **W6** | 일일 시드 챌린지 + 스팀 리더보드 연동. |
| **W7** | 아트·사운드·UX 폴리시. 튜토리얼. 저사양 최적화. |
| **W8** | 소규모 스트리머 키 배포 → 피드백 → 버그픽스 → **스팀 출시**. |
