## 2. 산업별 활용 시나리오

### 2.1 스마트 팩토리 / 제조

#### 시나리오 A: 전력 수요 예측 및 피크 제어

```
[태그 입력]                    [AI Engine]              [태그 출력]
현재 전력(kW) ──────→  predict.power  ──────→  예측 전력(kW)
외기 온도     ──────→  (ONNX 모델)   ──────→  피크 확률(%)
생산 스케줄   ──────→               ──────→  절감 가능량
                                            ──────→  피크 알람
```

**효과:**
- 전력 피크 15분 전 사전 경고
- 부하 분산 자동 제어 (비필수 장비 순차 정지)
- 전력 요금 10~15% 절감 (피크 관리)

#### 시나리오 B: 설비 이상 감지 (Anomaly Detection)

```
[주기 실행: 10초]
진동 센서 → Z-score / IQR 분석 → 이상 판정 → 알람 태그
전류 센서 → 이동평균 편차 분석 → 트렌드 → 유지보수 알림
온도 센서 → 비교 분석 (정상 범위) → 등급 분류
```

**사용 스크립트:**
```python
import numpy as np

values = [tag_read(t) for t in payload['sensor_tags']]
mean, std = np.mean(values), np.std(values)

anomalies = [v for v in values if abs(v - mean) > 3 * std]
if anomalies:
    tag_write('Equipment.AnomalyFlag', 1)
    log_warning('이상 감지: %d건' % len(anomalies))

emit_result({'anomaly_count': len(anomalies), 'mean': round(mean, 2)})
```

#### 시나리오 C: 생산 품질 예측

- 원자재 투입 → 공정 파라미터 → 품질 예측 모델(sklearn)
- 불량률 예측 시 공정 파라미터 자동 조정
- 품질 이력 데이터 누적 → 모델 재학습

### 2.2 빌딩 에너지 관리 (BEMS)

#### 시나리오 D: 실시간 에너지 최적화

```
[입력 태그]                      [AI 분석]               [출력 태그]
실내 온도 ───────→                              ───→ 냉난방 설정온도
외기 온도 ───────→  에너지 최적화              ───→ 공조 가동률
습도      ───────→  스크립트                   ───→ 조명 밝기
재실 인원 ───────→  (numpy/pandas)            ───→ 에너지 절감률
전력 사용 ───────→                             ───→ 목표 대비 진행률
태양광 발전───────→                             ───→ ESS 충방전 명령
```

**핵심 알고리즘:**
- 시간대별 에너지 패턴 분석 (analysis.trend)
- 외기온도-냉방부하 상관분석 (analysis.correlation)
- 최적 설정온도 예측 (predict.power + 커스텀 모델)
- PMV(예상 평균 온열감) 기반 쾌적성 유지

#### 시나리오 E: 에너지 소비 리포트 자동 생성

- 일/주/월 단위 에너지 사용량 집계
- 전년 동기 대비 분석
- 원단위 에너지 (kWh/m2) 자동 계산
- 탄소배출량 환산 (tCO2)

### 2.3 수처리 / 환경

#### 시나리오 F: 수질 예측 및 약품 투입 최적화

- pH, 탁도, 잔류염소 센서 → 수질 예측 모델
- 최적 약품 투입량 계산 (과투입 방지)
- 이상 수질 사전 경보

### 2.4 신재생 에너지

#### 시나리오 G: 태양광/풍력 발전량 예측

- 기상 데이터 + 과거 발전량 → 발전 예측
- ESS 충방전 스케줄 최적화
- 계통 연계 출력 제어

## 4. 경쟁 우위

### 4.1 기존 SCADA + AI 연동 방식 비교

| 방식 | 구현 복잡도 | 실시간성 | SCADA 연동 | 비용 |
|------|-----------|---------|-----------|------|
| 별도 AI 서버 + API 연동 | 높음 | 느림 (HTTP) | 별도 개발 | 높음 |
| 클라우드 AI 서비스 | 중간 | 느림 (인터넷) | 별도 개발 | 구독비 |
| SCADA 내장 스크립트 | 낮음 | 빠름 | 직접 | 없음 |
| **Autobase Python AI** | **낮음** | **빠름 (TCP)** | **내장** | **포함** |

### 4.2 차별화 포인트

1. **제로 설정:** Autobase 스크립트에서 `PythonAiCall()` 한 줄로 AI 호출
2. **SCADA 네이티브:** 태그 읽기/쓰기가 AI 스크립트 내에서 직접 가능
3. **안전:** 5계층 샌드박스 — 산업 현장에서 안심하고 사용
4. **확장:** ONNX 모델 드롭인 배포, 운영 중단 없이 모델 교체
5. **비용:** 별도 AI 서버 불필요, Autobase 라이선스에 포함 가능

## 5. 도입 로드맵

### Phase 1: 기본 활용 (즉시 가능)

- Autobase 스크립트에서 PythonAi 함수 호출

- 다중 모델 앙상블, A/B 테스트
