## 2. 시제품 기능 범위

### 2.1 MVP 기능 (시제품 핵심)

#### 기능 1: 에너지 대시보드 + AI 예측

- 실시간 전력/가스/수도 사용량 모니터링 화면
- AI 기반 전력 수요 예측 (1시간/24시간 선행)
- 예측 vs 실제 비교 차트
- 피크 알람 및 부하 관리 권고

**구현 방식:**
```
Autobase 그래픽 화면
├── 실시간 태그 표시 (기존 기능)
├── 예측 차트 (PythonAiPredictPower + 태그 출력)
├── 트렌드 표시 (PythonAiTrend)
└── 알람 로직 (PythonAiScript → tag_write)
```

#### 기능 2: 설비 이상 감지

- 냉동기/보일러/공조기 센서 데이터 실시간 분석
- Z-score 기반 이상 감지 (script.execute)
- 설비 상태 등급 표시 (정상/주의/경고/위험)
- 이상 발생 시 자동 알람 + 이력 기록

#### 기능 3: 에너지 절감 리포트 자동 생성

- 일/주/월 에너지 사용량 집계 (script.execute + pandas)
- 전년 동기 대비, 목표 대비 분석
- 원단위 에너지, 탄소배출 환산
- PDF/화면 리포트 자동 생성

#### 기능 4: 쾌적성 분석

- 온도/습도/CO2 기반 실내 환경 평가
- PMV(예상 평균 온열감) 계산 (script.execute)
- 에너지 효율과 쾌적성 균형점 탐색

### 2.2 확장 기능 (향후)

| 기능 | 설명 | 필요 기술 |
|------|------|-----------|
| 태양광 발전 예측 | 기상 + AI 모델 | predict + 기상 API |
| ESS 충방전 최적화 | 요금 + 발전 예측 | script + 최적화 모델 |
| 설비 수명 예측 | RUL 모델 | predict + sklearn |
| 자동 설정 제어 | AI → 설정온도 자동 변경 | script + tag_write |
| 계기판 OCR | 아날로그 계기 자동 판독 | vision.ocr |

## 5. 기술 차별화 포인트 (특허/마케팅용)

### 5.1 특허 출원 후보

| 제목 | 핵심 |
|------|------|
| SCADA 내장형 AI 추론 엔진 | HMI에 AI 엔진을 내장하여 별도 서버 없이 실시간 추론 |
| Preload/Snapshot 기반 SCADA-AI 데이터 교환 방법 | C#이 태그를 미리 읽어 Python에 전달, 결과를 다시 태그에 쓰는 패턴 |
| 5계층 보안 샌드박스 스크립트 실행 방법 | 산업 제어 시스템에서 안전한 사용자 스크립트 실행 |
| 3-Tier AI 모델 추론 방법 | 모델 → 통계 → 폴백 자동 선택 |

### 5.2 마케팅 키워드

- **"AI 내장 HMI"** — 별도 AI 서버 없이 HMI 자체에서 AI 추론
- **"SCADA 네이티브 AI"** — 태그 시스템과 AI가 직접 연동
- **"드롭인 AI 모델"** — ONNX 모델 파일만 넣으면 즉시 적용
- **"안전한 AI 스크립트"** — 5계층 보안으로 산업 현장 안심 사용
- **"제로 코딩 AI"** — 기존 Autobase 스크립트에서 함수 호출만으로 AI 활용
