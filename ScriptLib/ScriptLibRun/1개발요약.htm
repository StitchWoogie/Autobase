3) character 변환 (문자열 변환도 동일)

escape 문자는 ', ", \, 0, a, b, f, n, r, t, u, U, x, v 의 14개가 있다. 아래와 같이 가능

u,U 는  \u0000~\uFFFF 까지 반드시 4자리를 사용해야 한다.

u,U 는  \u0~\uFFFF 까지 반드시 1~4자리를 사용한다.

a = '\''; b = '\"'; c = '\\'; d = '\0'; e = '\a'; f = '\b'; g = '\f'; h = '\n'; i = '\r'; j = '\t'; k = '\u1111'; l = '\U1111'; m = '\x30'; n = '\v'; o = 'A'; p = '한';
